# ADR-0009: Distinguish `import` Sources from `reference` Sources

## Status

✅ Accepted

## Context

[data/sources.yaml](../../data/sources.yaml) is cited from two structurally different places:

- an **entry**'s `sources:`, recording where its content came from; and
- a **phonology mapping**'s `sources:` (ADR-0003), recording the evidence a confidence rests on.

These are not the same relationship. A grammar or a published phonology chart is *consulted*; its
text is never reproduced. Wiktionary is *copied out of*. Before the distinction existed, the
registry could not tell them apart, and some sources carried a placeholder `licence: unknown`.

The failure mode is specific and severe. Wikipedia has a real, share-alike licence. If an entry
could cite `wikipedia` as a source, ADR-0008's derivation would faithfully relicense that entry
CC-BY-SA-4.0 — correctly, given the citation — even though nothing was copied from Wikipedia and
the citation only meant "this is where I checked the tone". The dataset would acquire share-alike
obligations from evidence, not from content.

## Decision

Every source carries a **`kind`**:

- **`import`** — material is copied out of it into the dataset. `licence` is **required**, and
  `import` is the default for a source that doesn't declare a kind.
- **`reference`** — cited as evidence, never reproduced. `licence` is **optional**, since no
  licence obligation attaches to material that was never copied. `pengim-1960` and `learnteochew`
  carry none.

The rules the validator enforces:

- An **entry**'s `sources:` may cite only `import` ids. Citing a `reference` source is rejected,
  not silently accepted.
- A **phonology mapping**'s `sources:` may cite either, because a mapping records evidence about
  the language rather than the origin of an entry's content.

`wikipedia` is `kind: reference` despite having a real share-alike licence — that classification is
precisely what stops it contaminating the dataset. `hsk-vocabulary` is `reference` for the same
reason (ADR-0022): the band is consulted to derive `level`, never reproduced.

Added in issue #11 (2026-07-30), which also dropped the stale `licence: unknown` placeholders.

## Consequences

- **ADR-0008's derivation is sound.** It can treat every id an entry cites as a genuine licence
  obligation, because nothing else can get into that list.
- "Where did this content come from" and "what evidence supports this analysis" become separately
  answerable, from the same registry, without conflating them.
- A reference work can be cited freely — the thing you most want to encourage — with no licence
  consequence and no need to hunt down its terms first.
- Negative: adding a source now requires a judgement about which kind it is, and the judgement can
  be wrong in a way that matters. A source misclassified `reference` while being copied from would
  under-report obligations. The validator checks the structural rule, not the classification.
- Negative: the boundary can blur for a source used both ways. The registry has no way to express
  "reference for phonology, import for glosses"; such a source would have to be split into two ids.
